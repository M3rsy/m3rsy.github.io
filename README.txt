DATOS ADAPTADOS

- Perfil profesional
- Stack tecnológico
- Experiencia profesional
- Educación
- Certificaciones y conocimientos
- Idiomas
- Datos de contacto

IMPORTANTE
El CV fuente no contiene una fotografía profesional, URL de LinkedIn ni URL de GitHub.
Por ese motivo:
1. La imagen assets/img/perfil.jpg es un placeholder con iniciales.
2. Los botones GitHub y LinkedIn contienen "#" para que puedas agregar tus enlaces reales.

CAMBIAR LA FOTO
Reemplaza:
assets/img/perfil.jpg

por tu fotografía real manteniendo el mismo nombre.

RECOMENDACIÓN DE FOTO
- Vertical
- Buena iluminación
- Fondo limpio
- 900 x 1200 px o proporción similar

ABRIR EL SITIO
Solo abre index.html en Chrome, Edge o Firefox.

GUARDAR COMO PDF
En la página pulsa "Guardar como PDF" y selecciona la impresora:
"Guardar como PDF".

DEPENDENCIAS
Google Fonts y Font Awesome se cargan desde Internet.
